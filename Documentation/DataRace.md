# データ競合

マルチタスクで処理を行っていると、複数のタスクから同じデータにアクセスしたときにデータが壊れることがあります。この現象を `データ競合` と呼びます。

データ競合が発生する理由は、複数のタスクでひとつのデータを同時操作しているときに、どこかで書込操作が行われていると、その書き込みが途中のうちに別のタスクが読み込んでしまうことになります。この問題はたまたま同じタイミングで読み書きが発生したときだけに起こるため、再現性が低く、想定しないデータによって深刻な影響が及ぶこともあって厄介です。

Swift には、データ競合を回避するための幾つかの方法が用意されています。
ここではそれを学んでいこうと思うのですが、データ競合に馴染みがないと、どのような問題が起こるかイメージしにくいところがあるので、まずは実際にデータ競合を発生させてみましょう。


## 課題

２週間分の天気をそれぞれ sync var を用いて取得します。取得した天気は配列に入れ、全部が揃った段階でテーブルビューに表示してください。

このとき、データの取得は Dispatch による並行処理で取得し、ロックなどのデータ競合対策は取らないようにします。そうして実際に、期待したのと違う結果が得られることを確認できたら、本課題はクリアです。

- ２週間分の天気を sync var で取得する。
- それぞれの天気は Dispatch を使った並行処理で取得する
- すべての天気が取得できたら、テーブルビューに一覧表示する
